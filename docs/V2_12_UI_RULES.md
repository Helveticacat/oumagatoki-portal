# オウマガトキ — v2.12 UIルール追補

## 幹部カード

- ホームと同じコンポーネントの思想：背景写真（右）＋ダークグラデーション（左）＋日本語見出し・英語補助表記・右シェブロン。
- 「タスク管理」「マニュアル」「決定事項」の**タイトル左のアイコンは置かない**。
- タスクカードだけ、ラベル付き小さなピルで4ステータスの件数を横並び表示する。
- ピルの色は未着手＝グレー、進行中＝青、確認待ち＝金、完了＝緑。色以外に状態名と件数を示す。
- カードのタップ操作は既存の管理一覧へ遷移する。

## アンケート背景

- v2.11で生成した掲示板・ランタン・投票箱のシーンを継続使用。
- 画像の上部をトリミングし、建物・掲示板・ランタンをヘッダー下から見える構図を維持。
- ヘッダー・ヒーロー・コンテンツは画像を途切れさせず連続させる。境界線は追加しない。
- ライトモードでもこの背景は暗く保ち、メッセージパネルの視認性を維持。

この追補は最新の確定フィードバックであり、旧UI_SPEC/DESIGN_GUIDELINESとの競合時にはユーザーが後から確定した修正を優先する。
