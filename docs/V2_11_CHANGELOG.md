## 画像ファイル

`assets/survey_bg.webp`、`assets/officer_bg.webp`、`assets/card_tasks.webp`、`assets/card_manual.webp`、`assets/card_decisions.webp`。

上記は**制作・引き継ぎ用の画像ファイル**です。配布 `index.html` にはすべて `data:` URI として含めているため、GitHub Pagesで利用する際はHTML単体の上書きでも表示できます。生成画像にエンブレムやUIテキストは焼き込まず、正式エンブレム・テキスト・リンク・状態表示はHTML側で描画します。

## 維持する機能・制限

- HOMEのお知らせ独立アコーディオン、HOME掲載フラグ複数指定、記事の編集、掲載期限
- 馬車の月間カレンダー、前月・翌月、長い担当者名の全文モーダル
- 幹部の4ステータス、タスク詳細モーダル、編集・削除・ゴミ箱復元、画像の複数添付とスワイプ
- マニュアルと決定事項の閲覧・編集、一般／幹部表示のデモ切替
- 端末設定によるテーマ初期値と手動変更。ダークな背景を優先するページでは、ライトモードでも画像背景は暗色を維持
- GitHub Pagesの公開プロトタイプのみ。ログイン、権限・共有保存、Sheets/GASは**未実装**。実データや秘密情報は使用しない
