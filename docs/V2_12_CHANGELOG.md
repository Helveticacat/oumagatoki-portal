# オウマガトキ GUILD PORTAL — v2.12 変更記録

- バージョン: v2.12（v2.11のデザイン微調整）
- 対象: 幹部ワークスペースの大型リンクカード、アンケート背景
- 状態: 公開前プロトタイプ。GitHubには未反映。

## 今回反映したフィードバック

### 幹部ワークスペース
- 背景はv2.11の「窓・旗・執務机・ランタン」画像を維持。ヘッダー〜コンテンツの背景の連続性を維持。
- タスク管理・マニュアル・決定事項の3カードで、見出しの隣にあった装飾アイコンをDOMから削除。
- 見出し・英字サブタイトル・右矢印・背景写真の構成は、HOME画像リンクと同じ左テキスト＋右ビジュアルに合わせた。
- タスク管理カードを他の2カードより少し高くし、下段にコンパクトなアウトラインピルを横並びで表示。
- **確定仕様の4ステータス「未着手／進行中／確認待ち／完了」はすべて維持**。件数は既存タスクデータから動的に算出。
- カード遷移・タスク詳細・タスク編集・マニュアル・決定事項の機能には変更なし。

### アンケート
- 以前のアンケート専用背景の上辺を106px（元画像900×1350）トリミング。
- 掲示板、ランタン、投票箱がより上に見えるよう配置を調整し、写真の質感は維持。
- ページ全体のシームレス背景と「準備中」表示はそのまま。
- HTML内にトリミング後の画像を埋め込み済み。

- Chromium、幅320／375／390／430／520px、ダーク／ライトの2テーマ、全5画面を確認。
