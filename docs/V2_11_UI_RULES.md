# オウマガトキ GUILD PORTAL — v2.11 UI仕様追補

## 位置づけ

`docs/REQUIREMENTS.md` と `docs/UI_SPEC.md` と `docs/DESIGN_GUIDELINES.md` の補足。確定ビジュアルの3画像、後から確定した画面機能を優先する。

## 共通（HOME以外）

- ヘッダーの英字ブランドは上下ともゴールド（既存 `#EDC08A`）、セリフ体。字間 `.047em` を基準にする。HOMEの中央タイトルと同じ印象にする。
- すべてのページで画像背景はヘッダー→ヒーロー→コンテンツまで切らずに連続。罫線・色面でヒーローを独立ブロックにしない。
- ヒーローのアイコンと日本語タイトルは同一の垂直中央線で光学調整。SVG 29px前後、描画枠33px、文字22px程度を初期案とする。
- 英字のページサブタイトルは不要。デザインのためだけに再追加しない。
- 背景素材は文字、ロゴ、矢印、ボタンを含まない。これらはHTML/CSSで個別描画する。

## お知らせ・馬車

- お知らせのヒーロー内見出しをやや上に配置し、投稿ボタンまでの余白を広げる。記事の表示・編集・アコーディオンは変えない。
- 馬車は7列・月曜始まりのまま、馬車が短いヒーロー領域から視認できるよう背景位置を上へ調整。
- 長い車掌名は2行省略＋タップによる全文表示を維持。幹部印と凡例の ✦ を一致させる。

## アンケート

- 見出しアイコンを他ページと同じ視覚サイズに揃える。
- 新規背景：暗い城門、掲示板、投票箱、ランタン。文字を重ねやすい暗い余白を確保する。
- 機能は引き続き「準備中」。サンプル画面に実投票の操作を設けない。

## 幹部ワークスペース

- 背景：HOME「幹部ワークスペース」画像カードの窓・旗・ランタン・執務机を基準にした、縦長の連続背景。
- ヒーロー右側の別エンブレムは表示しない。共通ヘッダーの元エンブレムは維持。
- 画像付き導線カード3つはHOMEの大型画像リンクと同じ、高さ、余白、薄い金枠、ダークグラデーション、右側の矢印を使う。
- タスク管理のみ4ステータスの件数を**小さな横帯**で同一カード内に表示する。「未着手／進行中／確認待ち／完了」は名称でも判別できること。
- タスクカードをタップすると従来どおりタスク一覧に遷移し、詳細モーダル・編集・削除・復元・画像表示は維持する。

## デザイン検証

採用前に320px、375px、390px、430px、520pxの幅を検証し、ダーク・ライトとも文字欠けやボタンの重なりがないことを確認する。ライトは暗色の背景画像を維持してよいが、本文と操作の視認性を優先する。
