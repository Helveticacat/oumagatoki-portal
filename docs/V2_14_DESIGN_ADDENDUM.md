# GUILD PORTAL — v2.14 デザイン確定事項・Codex引き継ぎ

**適用先:** `index.html`（v2.14） / **更新方針:** 既存の3つの基幹Markdownは維持し、これまでの追補を最新の確定判断として参照する。

## 確定済みの全体ルール

- モダン・タクティカル／ポストアポカリプス。チャコール、ブラック、温かいゴールド。英数字はセリフ、日本語は太すぎないゴシック。
- HOMEは共通ヘッダーを使用せず、エンブレムとゴールドの2行英字タイトルを中央配置。歯車の設定アイコンを使用。
- 下層ページは共通のコンパクトなヘッダー、ヒーロー、本文エリアの背景が連続する。境界線で背景を分割しない。
- 下層ヘッダーの `OMAGATOKI` と `GUILD PORTAL` は金色・文字間を詰めた英字セリフ体。
- ヒーローの日本語タイトルと隣の線画アイコンは天地中央を光学的に揃える。英語のページ副題は使わない。
- レスポンシブ表示はiPhone縦長優先。ダーク／ライトの切替で背景の世界観を維持する。

## HOME / お知らせ / 馬車 / アンケート

- HOMEのギルド馬車・幹部ワークスペース導線カードは、高密度な背景写真に左側の暗い文字領域、薄い金色の枠、右のシェブロンを重ねる。
- お知らせは複数アコーディオン、カテゴリと重要度のアウトラインラベル、投稿・編集、HOME掲載制御を維持する。
- 馬車は月曜始まりの7列カレンダー、月送り、担当者名の省略と全文ポップアップ、幹部印✦と凡例の一致を維持。
- アンケートは掲示板・ランタン・投票箱の背景で、機能は『準備中』。アイコンは縮小済み。

## 幹部ワークスペース：v2.14最終反映

- 背景は独立した執務室画像。画像自体に文字や見出しを描かない。
- `タスク管理`、`マニュアル`、`決定事項` はHOMEの画像リンクと同じコンポーネント思想。タイトルの左側にアイコンは表示しない。
- カード内の写真は引きの構図と複数モチーフを使い、HOMEリンクカードと同程度の密度・解像感・奥行き・ランタン光を維持する。単一被写体への極端な寄りやぼけは避ける。
- タスク管理のみ4つのステータスの件数を灰／青／金／緑の小さなピルで表示。件数は実データから動的に計算する。
- v2.14でカード背景3枚を刷新。見出し文字、金枠、カード寸法、シェブロン、既存JavaScriptは維持。
