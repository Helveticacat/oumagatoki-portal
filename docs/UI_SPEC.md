# オウマガトキ GUILD PORTAL — UI SPEC

**Version:** 2.0 / 2026-11-27  
**対象:** v3.0プロトタイプ／将来の本番実装  
**位置づけ:** ユーザーが確定した画面構成・操作を記録する仕様。デザインは `DESIGN_GUIDELINES.md` に従う。

## 1. 実装段階と前提

- **【確定】** iPhone縦画面を基準に、Webブラウザで使う。無料運用優先。
- **【確定】** 初期公開の画面群は、ログイン／登録・HOME・お知らせ・馬車・ギルドルール・幹部ワークスペース・メンバー管理・設定。タスク管理・アンケートは保留。
- **【確定】** 一般ナビ `HOME / お知らせ / 馬車 / ルール`、幹部は `幹部` を追加。ルールのアイコンは本。アンケートは非表示。
- **【確定】** 一般メンバーには幹部画面を出さない。本番では画面表示だけでなくサーバー・DB側で権限を検査する。
- **【確定】** 現在のGitHub Pages版は**サンプルデータのみを扱う公開プロトタイプ**で、ログイン／DB共有保存／画像の安全な保管／定期サーバー実行／Sheets連携はまだ本番動作ではない。GitHub Pagesに秘密情報・実メンバーの非公開情報を配置しない。

## 2. 共通UI

- ヘッダー：**下層ページ共通・コンパクト**。既存エンブレム＋「OMAGATOKI / GUILD PORTAL」＋歯車メニュー。HOMEは専用KV内の歯車メニュー。
- 歯車メニュー：アカウント設定、権限表示切替（**プロトタイプのみ**）。本番のロール変更は権限管理に従う。
- テーマ：ダーク固定。端末設定と手動切り替えを使用しない。
- 下部ナビ：タップ領域を十分に確保し、選択中・幹部を明確に識別。
- ページのタイトルと背景画像は、ヘッダーとは別の**コンパクトなヒーロー領域**に配置する。

## 3. HOME

**目的：** 頻繁に使う機能へ最短でアクセスし、指定されたお知らせをその場で確認する。

### 要素の順序

1. 専用KV（エンブレム・サイトタイトル・サブタイトル・歯車設定）。
2. ギルド馬車の背景画像付きリンクカード。
3. お知らせ見出しと「すべて見る」リンク。
4. **HOME掲載指定のお知らせ**（該当するものをすべて表示、アコーディオン）。掲載ゼロ時は一覧への画像付きリンクカード。
5. 下部固定ナビ。幹部ワークスペースは下部ナビからのみ移動し、HOMEのリンクバナーは表示しない。

### お知らせのHOME掲載ルール

- **【確定】** 投稿・編集画面の `HOMEに掲載する` チェックで指定。
- **【確定】** 複数指定可能。**上限1件・自動入れ替えは廃止**。
- **【確定】** 複数記事のアコーディオンを同時に開ける。初期状態は閉じる。
- **【確定】** HOME掲載終了日時は記事ごとに任意設定でき、期限後はHOME掲載から外れる。お知らせ一覧から直ちに消すわけではない。
- **【確定】** `HOME掲載指定0件` の場合、お知らせの空欄パネルは表示せず、**お知らせ一覧へのリンクカード**のみ出す。
- **【暫定】** 表示順は新着順。別の並び替えが必要なら明示的に変更する。

## 4. お知らせ一覧・記事編集

- **【確定】** 一覧はアコーディオン形式。複数同時展開可能。
- **【確定】** カテゴリ絞り込み、本文コピー、重要記事の一覧上部固定。
- **【確定】** 記事ごとに「確認しました」ボタンの有無を設定可能。単に開いたことを「確認済み」とは扱わない。
- **【確定】** 投稿・編集は幹部。タイトル、カテゴリ、本文、HOME掲載、重要固定、確認ボタン、HOME掲載終了日時を扱う。
- **【確定】** HOMEのお知らせ本文は同じ画面で開閉。詳細ページへの遷移を必須としない。
- **【確定】** 初期版では検索・年月絞り込みは不要。
- **【後続機能】** 投稿テンプレート、コメント・返信、承認者／未確認者一覧、予約公開、更新履歴などは過去に要件定義済み。実装時は本番のアクセス制御と合わせて検討。

### 4.1 ギルドルール・幹部用マニュアル・メモとの共通UI

- お知らせと同じ見出し・カテゴリタグ・絞り込み・アコーディオンカード。初期は閉じ、複数記事を同時に開ける。
- 本文コピー、幹部の新規投稿・編集を共通化。ギルドルールは全メンバー閲覧可。幹部用マニュアル・メモは幹部のみ閲覧・編集。
- ルールのナビは本の線画。カテゴリ名と並び順は仮。幹部用マニュアル・メモの検索、画像添付・閲覧、編集履歴、アーカイブ、リッチテキスト、資料リンクの既存要件を保持。
- v3.0試作は一時データのみ。幹部用マニュアル・メモの検索・画像添付・ギャラリーを試作対象とする。履歴・アーカイブ・リッチテキスト・資料リンク等の本番要件は未実装。

## 5. ギルド馬車

- **【確定】** 既存のGoogleスプレッドシートとGASで編集・出力し、Webサイトは**閲覧専用**。
- **【確定】** 出力先：`https://docs.google.com/spreadsheets/d/1kuVf7BfIiPZqhnfLLQTn_zK5u-za4jXESNZAuA1gAew/edit?gid=1045359656#gid=1045359656`。対象タブ `gid=1045359656`、主な対象範囲 `B4:H13`、日付と車掌名が交互の行。
- **【確定】** 表示はスマホ向け**月間カレンダー**。月送りを提供。日付と車掌名が必須。幹部の印は出力から判別できる場合のみ表示。
- **【確定】** 選択中の日付の詳細カードは**不要**。長い担当者名を確認する既存のポップアップは維持（別置きの詳細カードは不要）。
- **【確定】** 共通ヘッダー下の馬車用ビジュアル・ページタイトルは短く整理し、カレンダーが画面上部から十分見えるようにする。
- **【本番実装要件】** Sheetsは非公開のまま、認証済みの会員だけが取得できるサーバー側の経路を使う。公開CSV・誰でも読めるGAS API・ブラウザ内の秘密鍵は禁止。元シートの変更は最小限にする。

## 6. 幹部ワークスペース

- **【確定】** 幹部8人全員が幹部用マニュアル、メモを作成・閲覧・編集できる。
- **【確定】** `幹部用マニュアル / メモ` の2つの画像付きカードを表示。タスク管理のバナー・件数・ページは非表示。

### タスク一覧・カンバン（保留）

以下は復活時の旧確定要件。v3.0では非表示。

- **【確定】** ステータス：`未着手 / 進行中 / 確認待ち / 完了` の4種類。関連する件数・絞り込み。
- **【確定】** タスクカードをタップして**詳細モーダル（ポップアップ）**を開く。カード内の「次の状態へ」ボタンを削除する。
- **【確定】** 詳細・メモをカード／モーダル内で確認し、編集ボタンで編集フォームを開く。
- **【確定】** 管理項目：タイトル、複数担当者、期限、優先度、詳細・メモ、繰り返し設定、変更履歴。
- **【確定】** 削除は確認ダイアログを経由した論理削除。ゴミ箱画面から復元できる。
- **【確定】** 添付画像は複数枚。スマホの写真ライブラリ・カメラ・ファイルから選択可能。閲覧は左右スワイプ。
- **【確定】** 定期タスクは曜日・日付を細かく指定し、**指定日時に自動生成**。本番ではサーバー側で二重生成防止と権限検査を実装。
- **【確定】** タスク通知は期限前日・当日、期限超過（サイト内）。アプリを閉じた端末へのプッシュ通知を保証するものではない。

### 幹部用マニュアル・メモ

- **【確定】** サイト内で作成・編集。カテゴリ別の情報整理。日本語のリッチテキスト編集。
- **【確定】** メモは旧決定事項の記録用途を保持する。関連資料・Google Driveリンク、キーワード検索、編集履歴と過去版、アーカイブ。
- **【確定】** 複数画像の添付とスワイプ閲覧を共通利用する。

## 7. 認証・メンバー・サイト管理

- **【確定】** プレイヤー名＋個別パスワード。メール登録は不要。
- **【確定】** 初回は既存名簿からプレイヤー名を選び、指定幹部がゲーム内で本人確認して承認。承認前は内部情報へアクセス不可。
- **【確定】** 名前変更、承認、脱退処理は指定した一部の幹部のみ。重複名は禁止。
- **【確定】** パスワード再設定はゲーム内DMで本人確認後、期限付きで一度しか使えない手段を採用。幹部はパスワードを閲覧できない。
- **【確定】** 脱退者のアカウントと個人情報を削除する。監査ログ・馬車担当記録との両立には匿名化等の詳細設計が必要。
- **【確定】** サイト全体構造、権限設定、外部連携、デザイン、公開・更新はサイト管理者のみ。初期1名＋幹部1名をバックアップ管理者に追加でき、後から管理者を追加・削除できる。幹部8人のコンテンツ編集権限とは分離する。

## 8. アンケート（保留・非表示）

- **【確定】** ページ・ナビともに非表示。既存要件は復活時のため保持。
- **【後続要件】** 単一選択／複数選択／自由記述、複数設問、匿名・記名と結果閲覧範囲のアンケートごと指定、プレビュー、複製、CSV出力、回答締切と集計。

## 9. v3試作と本番の境界

| 機能 | v3操作確認用 | 本番サイト |
|---|---|---|
| 下部ナビ・ページ遷移・月送り | 実際に動く | 継続 |
| お知らせ・ルール・幹部資料の編集 | サンプル状態、リロードで消える | 複数端末・複数幹部で共有保存 |
| 画像追加・スワイプ | ブラウザ内で仮保持 | 認証付き安全なストレージ |
| 定期タスク | 非表示・保留 | 復活時に指定日時にサーバー側で自動生成 |
| 馬車 | サンプルの月間カレンダー | 非公開のSheets/GASへ安全に連携 |
| ログイン・権限 | 見た目を確認する仮の切替 | サーバー側認証・権限・監査ログ |
