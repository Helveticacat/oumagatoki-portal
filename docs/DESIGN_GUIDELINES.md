# オウマガトキ GUILD PORTAL — DESIGN GUIDELINES

**Version:** 1.1 / 2026-11-27  
**Status:** ビジュアル指針・確定。数値トークンは実装用の初期提案（要検証）。  
**対象:** スマートフォン優先のギルド専用サイト（iPhone縦画面を基準）。

## 0. この文書の使い方・優先順位

実装・デザイン改修時には、次の順で判断する。

1. **後から承認された確定要件・フィードバック**（本リポジトリの `UI_SPEC.md` を含む）。
2. **本 `DESIGN_GUIDELINES.md`** のデザイン原則・トークン・コンポーネント仕様。
3. **承認済み画像3枚**：`references/home_approved.png`、`references/carriage_approved.png`、`references/officer_approved.png`。
4. その他の試作画面・生成画像・実装上の仮デザイン。

**重要:** 承認画像はビジュアルの参照であり、画面構成・文字・人数・日付・タスク件数をそのまま使う指示ではない。たとえば元画像にある大きなヘッダーは、後の「共通ヘッダーをコンパクトに」という指示により更新されている。

### 確定／推定の区別

- **【確定】** ユーザーが選択・承認した方向性や操作要件。
- **【画像観察】** 3枚の参照画像で実際に確認できる特徴。
- **【提案値】** CSS用のHEX・px等。画像のピクセルから厳密に指定されたものではなく、試作して検証するための初期値。

## 1. デザイン原則

1. **【確定】モダン・タクティカル**。ポストアポカリプス／ダークファンタジーを感じさせる、上質で重厚なUI。
2. **【確定】世界観は強めに表現するが、文字と操作は読めることを優先**。背景画像、灯り、金属調の縁取りなどで雰囲気を作り、文字の背後を複雑にしない。
3. **【確定】チャコール・ブラック＋温かいゴールド**を基調とする。オレンジのギルド旗をブランドの焦点にする。
4. **【確定】英数字はセリフ体、日本語はゴシック体**。日本語のウェイトは過度に太くしない。参照画像にある明朝風の文字形を再現することより、後のタイポグラフィ指定を優先する。
5. **【画像観察】装飾はカードとセクションを縁取る程度に集約**。背景全面をパネルや線で埋めない。
6. **【確定】既存エンブレムの形・色・紋様を保持**。生成時に別の紋章へ置き換えない。

## 3. カラーシステム

参照画像は光源・陰影・素材感が混じるため、下記の値は**すべて【提案値】**。画像から得られた厳密な色指定ではない。実機で視認性を確認しながら変更してよいが、変更はトークンに集約すること。

| トークン | ダーク初期値 | 用途 |
|---|---|---|
| `--color-bg` | `#11161C` | 画面背景 |
| `--color-surface` | `#20262C` | 情報カード、モーダル |
| `--color-surface-raised` | `#2A3036` | 選択・強調されたカード |
| `--color-text` | `#F1E9DE` | 見出し／本文 |
| `--color-text-muted` | `#B6B0A9` | 補足テキスト |
| `--color-gold` | `#D8AF70` | 選択、リンク、細い枠 |
| `--color-gold-subtle` | `#7D6547` | 目立ちすぎない枠線 |
| `--color-line` | `rgba(216,175,112,.30)` | 境界線 |
| `--color-emblem-orange` | `#C66D25` | 旗画像に由来するアクセントの目安。旗そのものは元画像を使う |
| `--color-danger` | `#CE7974` | 削除の確認・危険操作 |
| `--color-success` | `#789778` | 完了状態など |

**【画像観察】** 日曜は鈍い赤、土曜は青灰色の色面・文字が用いられる。タスクの4ステータスはグレー、青、金、緑のような色分け。これらは状態を色だけに頼らず、名称でも必ず表示する。

**【確定】** 現行ダークモードに固定。端末設定を参照せず、切り替えUIを廃止する。

## 4. タイポグラフィ

| 項目 | ルール |
|---|---|
| 日本語 | **【確定】ゴシック体**。推奨フォールバック：`"Hiragino Kaku Gothic ProN", "Noto Sans JP", "Yu Gothic", sans-serif` |
| 英数字・英字サブタイトル | **【確定】セリフ体**。推奨：`Georgia, "Times New Roman", serif`（ブランドフォントの最終選定は別途） |
| 日本語の太さ | **【確定】極太禁止**。本文 400、見出し 500 程度を基準にし、強調が必要な場合のみ 600（提案値） |
| 英字 | 【画像観察】`GUILD PORTAL` / `GUILD CARRIAGE` / `OFFICER WORKSPACE` などは字間が広い。字間 `0.12em–0.20em` は提案値 |
| 数字 | 【画像観察】月表示・タスク件数などの数字は装飾的なセリフ体が似合う |
| 最小サイズ | 【提案値】本文 14px 以上、補助 12px 以上、タップ領域 44px 以上を目安に。7列カレンダーは特に実機確認 |

**禁止:** 太い明朝体を視認性確保のために強制使用すること。背景写真の上に長い本文を直置きすること。すべての日本語に英数字用セリフフォントを適用すること。

## 5. 背景と写真

**【画像観察】**

- HOME：霧の城塞、暗い山肌・廃墟。シルエットが強く、文字エリアは暗く沈む。
- 馬車：帆馬車・ランタン・夕暮れ・オレンジの旗。写真／絵画的な背景が主役となるのはページ上部のみ。
- 幹部：城塞、資料・地図、革表紙の本、羊皮紙や封蝋、ランタンを各カードのテーマ画像に使う。
- 光は暖色。全面に派手な金色グローを広げない。

**【確定】** HOMEの馬車カードと幹部用マニュアル・メモの大型カードでは、背景画像を残す。**アイコンだけの無地カードへの置き換えは禁止**。画像右寄せ＋左側に暗いグラデーションを重ね、その上に文字を置く構成を基準とする。

**【提案値】** 写真の上の左側文字領域に `linear-gradient(90deg, rgba(10,15,20,.92), rgba(10,15,20,.42))` を重ねる。暗さ・不透明度は可読性で調整する。

## 6. レイアウト・部品

### 共通ヘッダー

**【確定】** 下層ページで同じ構造とし、HOMEは専用KVを維持し、**元の承認画像よりコンパクト**にする。エンブレム、サイト名／`GUILD PORTAL`、メニューをまとめて配置。ページごとのヒーロー画像・タイトルはヘッダーの下の小さめのセクションに表示。設定・権限表示切り替えは歯車メニュー内へ。テーマ切り替えは設けない。

**【提案値】** 高さ 72–88px、左右パディング 14–18px、エンブレム幅 38–48px。iPhoneのSafe Areaを考慮する。ヘッダー全体が縦画面の大きな部分を占有しないようにする。

### 大型画像カード

**【画像観察】** 枠は細い鈍い金、ほどよい角丸／コーナー装飾。画像は右半分、左に見出し・英字ラベル、右端に矢印。

**【提案値】** 高さ 108–144px、角丸 10–14px、余白 14–18px、枠 1px。細かな金の縁取りは残すが、階層を読みづらくする二重三重の装飾は避ける。

### 下部固定ナビ

**【確定】** 一般は `HOME / お知らせ / 馬車 / ルール`、幹部はそこに `幹部` を追加。幹部アイコンのみ特別な金系の演出をする。アンケートは保留・非表示。ルールは本の線画アイコン。ナビの各アイコンは内容と一致するもの（馬車、メガホン、王冠・盾など）。

**【確定】** ナビは少し高さを増やして押しやすくする。選択中の強調と未選択を区別する。Safe Areaを覆わない。設定はメニュー内からアクセスする。

**【提案値】** タップ領域最低44px、アイコン20–24px、ラベル11–12px、ナビの本体高さ約66–78px＋Safe Area。

### 月間カレンダー

**【確定】** 7列の月間表示、月送り、日付＋車掌名。選択日詳細の別カードは置かない。閲覧専用。幹部判別可能ならマークを付与。

**【画像観察】** 日曜を赤茶・土曜を青灰にし、セルは細い境界線。名前は小さなタグの中に表示。装飾はカレンダーの可読性を妨げない。

**【提案値】** 名前が長い場合に2行折り返し、省略表記、タップによる補足のいずれかを実装前に検証。狭い画面での横スクロールは原則避ける。

### モーダル・アコーディオン

**【確定】** お知らせ・ギルドルール・幹部用マニュアル・メモは同じカード・カテゴリタグ・絞り込み・アコーディオンUIで、複数同時展開可能。タスクの詳細は保留。画像は複数添付し左右スワイプで見る。確定画像の雰囲気を尊重しつつ、情報量の多いモーダルには背景写真を敷かない。

```css
  --color-text-muted: #b6b0a9;

  --color-line: rgba(216,175,112,.30);
  --color-danger: #ce7974;
  --color-success: #789778;
  --font-ja: "Hiragino Kaku Gothic ProN", "Noto Sans JP", "Yu Gothic", sans-serif;

```

これらは**固定された正解ではなく実装用の初期値**。値を変更する場合は個別ページでハードコードせず、デザイントークンを更新する。

## 8. 禁止事項・デザインレビュー

- 一度確定した背景画像付きカードを、理由なく文字＋アイコンのみのカードにする。
- 下層ページで共通ヘッダーの高さ・ロゴサイズ・ナビをバラバラにする（HOME専用KVは例外）。
- 日本語を極太明朝、英数字を無秩序にサンセリフへ変更する。
- 画面全体にグロー・罫線・ボーダーを足しすぎる。
- ゴールドを通常本文・大量の背景領域に多用する。
- 装飾性を優先してタップ対象や本文のコントラストを下げる。
- 承認画像中のダミーの日付・人物名・件数を実データと混同する。
- 未実装の認証やSheets連携を動作済みと表示する。

**改修前レビュー:** ①3枚と見比べる ②最新仕様と矛盾しない ③iPhone幅で文字が読める ④カード背景画像が保持される ⑤幹部／一般の違いが判別できる ⑥端末テーマを問わずダーク固定で破綻しない ⑦見た目以外の既存機能が動く。
